# nuwa-skill 拆解文档

这是对仓库 [nuwa-skill（女娲）](../../README.md) 的拆解，写给没有 AI 基础的老师和学生：帮你看懂“一个能模拟名人思维方式的 skill 到底是怎么做出来的”。

- 仓库许可证为 MIT（`LICENSE`）。本文档只引用、讲解，单次引用控制在几行内。
- 本目录是**新增**内容，没有改动原仓库任何文件。
- 每个结论后面标注依据的文件路径（必要时带行号）。**（推测）** 表示仓库没有明说、由我推断。
- 文中的“实测”指我在本仓库里实际运行了 `scripts/` 下的脚本或 `grep` 命令得到的结果，命令写在文中，可自行复现。

## 博客频道素材

[blog/](blog/00-频道策划.md) 目录是把以上拆解改写成博客/视频选题的素材：按代码模块拆分的 9 集策划，以及第一集旗舰篇草稿。

## 推荐阅读顺序

- **只想看懂原理**：00 → 01 → 02 → 05。
- **想动手做一个**：00 → 01 → 04（遇到“为什么”回头看 02）。
- **想判断它靠不靠谱**：02 → 03 → 05。
- **老师备课**：00 先讲全景；01 的“总结表”和 02 的“对比表”适合直接做成课件；03 可以当作“怎么评价一个 AI 产出”的案例。

## 先记住的几个词

| 词 | 一句话解释 |
|---|---|
| Skill | 一个文件夹，核心是一份 `SKILL.md`，写给 AI 看的“工作手册” |
| 提示词 | 写给 AI 的文字指令 |
| 子代理（subagent） | 主 AI 临时派出去分头干活的“分身” |
| 蒸馏 | 把一个人公开留下的大量内容，浓缩成“他怎么想问题”的规则 |
| 心智模型 | 一个人反复用来理解各种问题的思考套路 |
| 表达 DNA | 一个人说话的句式、用词、节奏等特征 |
| 保真度评分卡 | 衡量 skill “像不像、诚不诚实”的 100 分制测试 |

## 一个提醒

仓库的 15 个示例都被评为 A 级（89-97 分），但评分方法由作者体系自己设计，评分者也是 AI。请把它当作“作者自己的质检记录”，而不是第三方认证。详见 [03](03-示例对照分析.md) 与 [05](05-设计取舍与可改进之处.md)。
